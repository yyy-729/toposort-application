# 拓扑序设计器使用说明

适用版本：当前桌面应用（2026 年 9 月 23 日）。在程序顶部的**帮助 → 使用说明**也可以打开本文。

## 第一次使用：照着做一遍

1. 确认电脑已安装 Python 3.12。首次使用时，双击项目根目录的`安装依赖.bat`，等待出现安装成功提示。
2. 双击根目录的`启动应用.bat`。程序打开时，左侧已有一组内置示例。
3. 点击右上角的**运行分析**。中间显示关系图，右侧显示统计数字和排序结果。
4. 点击右侧的**智能分析**，查看并行阶段、最长依赖链等信息。
5. 点击右侧的**阶段规划**，把“每阶段最多”设为`3`，点击**生成规划**，查看分阶段结果和图中颜色变化。
6. 如需保存，点击上方**导出关系图**、**导出结果**，或阶段规划页的**导出规划**，在弹出的窗口选择保存位置。

平时只需双击`启动应用.bat`。根目录的英文`run_app.bat`和`install_dependencies.bat`是中文按钮文件调用的脚本，不需要分别操作。`本地视频材料/`中的启动文件是旧的中期演示原型，手动测试当前应用时不要从那里启动。

## 界面分为三块

| 位置 | 用途 |
|---|---|
| 左侧“关系数据” | 输入、粘贴或查看导入的先后关系 |
| 中间“关系图” | 查看有向箭头、切换布局、缩放与探索节点 |
| 右侧“分析结果” | 查看排序结果、智能分析和阶段规划 |

上方的**载入示例**会恢复程序内置的简短课程示例；**清空**会清除当前输入及分析结果。修改左侧内容后，需要再次点击**运行分析**，旧结果才会更新。

## 输入自己的关系

每行写一条关系，使用西文尖括号和西文逗号：

```text
<程序设计基础,数据结构>
<离散数学,数据结构>
<数据结构,算法设计>
```

`<A,B>`表示 A 必须先于 B。可以直接在左侧编辑，也可以点击**导入 TXT**选择 UTF-8 编码的文本文件；带 UTF-8 BOM 的文件也可导入。空行会忽略，重复关系会去重并提示。不要用中文逗号`，`；当前格式也不支持单独声明没有关系的孤立节点。

可直接试用以下文件：

| 文件 | 适合测试什么 |
|---|---|
| `examples/multiple.txt` | 简单的多种拓扑排序 |
| `examples/taskbook_figure1.txt` | 任务书图 1 的课程关系 |
| `examples/curriculum_2024_verified.txt` | 从《2024版学业指南》核实的部分课程先修关系 |
| `examples/cycle.txt` | 循环依赖提示 |
| `examples/invalid.txt` | 格式错误和行号提示 |

培养方案示例只包含已核实的部分先修关系，不代表完整选课规则；依据见[培养方案数据核对说明](培养方案数据核对说明.md)。

## 右侧三个页面怎么用

### 排序结果

点击**运行分析**后，这里列出符合全部先后关系的拓扑顺序。结果超过 50 条时，底部会出现**上一页 / 下一页**；翻页只改变屏幕上正在看的内容。

上方的**复制结果**会复制本次已经生成的全部排序，**导出结果**会把这些排序保存为 TXT，不只保存当前页。若状态显示“已截断”或“未完全枚举”，表示符合条件的排序还有更多，本次并未全部生成。

### 智能分析

这里可以查看拓扑序是否唯一、并行阶段、最大并行宽度、最长依赖链，以及可由其他路径推导出来的冗余关系。小规模图（不超过 18 个节点）还会精确计算全部可行顺序的总数；更大的图会跳过这项精确计数，以免等待过久。

**并行阶段**只根据先后依赖分组，不考虑“每阶段最多安排几项”。若要加数量限制，请使用**阶段规划**页。

### 阶段规划

先完成一次**运行分析**，再在此页设置**每阶段最多**安排多少个节点，点击**生成规划**。程序会列出每个阶段的节点，并在中间关系图按阶段着色。点击**导出规划**可保存 TXT。

- 图中节点不超过 14 个时，界面标注“精确最优”，表示已求得最少阶段数。
- 图中节点超过 14 个时，界面标注“启发式建议（不保证最优）”。这份安排仍满足先后关系和每阶段数量限制，但不承诺阶段数最少。
- “阶段数理论下界”是任何方案都不可能低于的阶段数，不一定等于实际可做到的阶段数。

如果把节点理解为课程，这个功能只能作为依据先修关系和课程数量得到的学习批次参考；它没有计算学分、开课学期或选修要求。改动“每阶段最多”后，需要重新点击**生成规划**。

## 几个数字不要混淆

| 界面文字 | 含义 |
|---|---|
| 结果上限 | 本次最多生成多少条拓扑排序，默认 1000 条 |
| 已显示 | 本次实际生成的排序数量；分页时不等于当前页条数 |
| 方案总数 | 全部可行排序的数量；仅在小规模图中精确统计 |
| 并行阶段 | 不限制每阶段节点数量时，按依赖关系得到的分层数 |
| 每阶段最多 | **阶段规划**中每个阶段允许安排的节点数量，默认 3 项 |

例如培养方案示例的精确方案总数是`185001600`，默认结果上限是`1000`：界面只生成并保存前 1000 条排序，不能把“1000 条已显示”理解成“总共只有 1000 种”。该示例有 16 个节点，因此容量限制规划显示的是启发式建议。

## 关系图的操作

- 箭头从前驱指向后继。图上方可切换**分层布局、力导向布局、环形布局**。
- 使用图上方的小工具栏缩放、拖动画面或恢复初始视图；工具栏中的保存按钮也可以保存当前图。
- 把鼠标移到长名称节点上，可查看完整名称。点击节点会高亮它的全部前置和后续节点，下方显示直接前驱与直接后继；再次点击可取消选中。
- 有可推导的冗余关系时，勾选**隐藏冗余边**可以简化画面，不会改变原始输入或排序约束。
- 点击右上角**深色模式**可切换主题。点击**导出关系图**可保存 PNG、SVG 或 PDF；复杂图导出时会使用更大的画布。

## 遇到问题时

- **按钮不能点击**：先运行分析；有格式错误或有向环时，不能生成有效排序和阶段规划。
- **提示第几行格式错误**：按提示检查该行的西文`< >`、英文逗号和两个非空节点名，修改后重新运行。
- **提示存在有向环**：关系中出现互相依赖，右侧会显示一条具体环路，图中也会高亮；先修改关系，才能得到拓扑排序。
- **结果显示“达到上限”**：可以调大上方**结果上限**并重新运行，但可行顺序很多时应保留上限，以免等待过久。
- **改了数据却看到旧结果**：输入变化会使旧结果失效，点击**运行分析**重新计算。
- **双击启动失败**：先运行`安装依赖.bat`；若仍失败，在 VS Code 的 PowerShell 终端运行`.\run_app.bat`，保留终端中的具体错误信息。

建议手动验收顺序：先用内置示例熟悉界面，再导入`examples/multiple.txt`看完整枚举，随后导入培养方案示例检查大量结果分页与阶段规划，最后用`examples/cycle.txt`和`examples/invalid.txt`检查异常提示。
