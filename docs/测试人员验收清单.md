# 拓扑序设计器测试人员验收清单

## 1 环境与启动

- [ ] Windows 10 或 Windows 11
- [ ] 已安装 Python 3.12
- [ ] 双击 `安装依赖.bat` 能够完成依赖安装
- [ ] 双击 `启动应用.bat` 能够打开程序
- [ ] 窗口中的中文、按钮和关系图显示正常

## 2 正常功能

- [ ] 载入内置示例后可以运行分析
- [ ] 节点数和关系数统计正确
- [ ] 关系图箭头方向正确
- [ ] 可以显示多个拓扑排序结果
- [ ] 结果数量与程序显示一致
- [ ] 修改结果上限后能够按上限输出
- [ ] 达到上限时显示“未完全枚举”
- [ ] 结果超过 50 条时可以翻页；复制和导出仍包含本次生成的全部结果
- [ ] 智能分析页能够显示方案总数、并行阶段和最长依赖链
- [ ] 能区分“结果上限”“方案总数”和“每阶段最多”
- [ ] 阶段规划满足容量和先后约束，正确标注精确最优或启发式建议
- [ ] 过程回放的候选、入度变化和最终顺序与排序结果一致
- [ ] 上一步、下一步、播放、暂停和切换页面后停止播放均正常
- [ ] 有向环时过程回放停止并说明原因
- [ ] 修改“每阶段最多”后需重新生成规划，旧规划不能继续导出
- [ ] 唯一拓扑序和多拓扑序能够正确区分
- [ ] 存在冗余关系时可以切换显示或隐藏
- [ ] 分层、力导向和环形布局均可切换
- [ ] 点击节点后能够高亮其前置和后续节点
- [ ] 深色与浅色主题显示正常
- [ ] 30 节点长链图和长节点名可辨认，悬停能看到完整名称

## 3 文件功能

- [ ] 可以导入 UTF-8 TXT 文件
- [ ] 可以导入带 BOM 的 UTF-8 TXT 文件
- [ ] 可以导出拓扑排序 TXT 结果
- [ ] 可以导出 PNG 关系图
- [ ] 可以导出 SVG 关系图
- [ ] 可以导出 PDF 关系图
- [ ] 可以导出阶段规划 TXT，内容与当前规划一致
- [ ] 长链和长名称导出的关系图中节点、文字与箭头可辨认

## 4 异常情况

- [ ] 中文逗号能够提示具体行号
- [ ] 缺少尖括号能够提示具体行号
- [ ] 空节点能够提示具体行号
- [ ] 三个字段能够提示具体行号
- [ ] 重复关系不会重复计数，并显示警告
- [ ] 自环能够提示存在环
- [ ] 普通有向环能够显示并高亮具体环路
- [ ] 空输入不会运行算法
- [ ] 不存在或编码错误的文件能够提示失败

## 5 状态一致性

- [ ] 修改输入后，旧结果和旧关系图不能继续导出
- [ ] 计算过程中输入区域不能修改
- [ ] 计算完成后输入区域恢复可编辑
- [ ] 有环时不会显示不存在的拓扑排序结果
- [ ] 关系图、统计数字和结果文本对应同一份输入
- [ ] 清空或修改输入后，旧阶段规划和阶段着色不再保留
