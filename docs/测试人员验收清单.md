# 拓扑序设计器测试人员验收清单

## 1 环境与启动

- [ ] Windows 10 或 Windows 11
- [ ] 已安装 Python 3.12
- [ ] 双击 `安装依赖.bat` 能够完成依赖安装
- [ ] 双击 `启动应用.bat` 能够打开程序
- [ ] 窗口中的中文、按钮和关系图显示正常

## 2 正常功能

- [ ] 载入内置示例后可以运行分析
- [ ] 节点数和关系数统计正确
- [ ] 关系图箭头方向正确
- [ ] 可以显示多个拓扑排序结果
- [ ] 结果数量与程序显示一致
- [ ] 修改结果上限后能够按上限输出
- [ ] 达到上限时显示“未完全枚举”

## 3 文件功能

- [ ] 可以导入 UTF-8 TXT 文件
- [ ] 可以导入带 BOM 的 UTF-8 TXT 文件
- [ ] 可以导出拓扑排序 TXT 结果
- [ ] 可以导出 PNG 关系图
- [ ] 可以导出 SVG 关系图
- [ ] 可以导出 PDF 关系图

## 4 异常情况

- [ ] 中文逗号能够提示具体行号
- [ ] 缺少尖括号能够提示具体行号
- [ ] 空节点能够提示具体行号
- [ ] 三个字段能够提示具体行号
- [ ] 重复关系不会重复计数，并显示警告
- [ ] 自环能够提示存在环
- [ ] 普通有向环能够显示并高亮具体环路
- [ ] 空输入不会运行算法
- [ ] 不存在或编码错误的文件能够提示失败

## 5 状态一致性

- [ ] 修改输入后，旧结果和旧关系图不能继续导出
- [ ] 计算过程中输入区域不能修改
- [ ] 计算完成后输入区域恢复可编辑
- [ ] 有环时不会显示不存在的拓扑排序结果
- [ ] 关系图、统计数字和结果文本对应同一份输入
