# 技术一核心功能说明

## 1 负责范围

技术一负责关系数据读取、格式检查、有向图构建、环检测、拓扑排序枚举和结果导出。图形界面和关系图绘制由技术二负责。

## 2 输入和输出

每个非空行使用 `<前驱,后继>` 格式。例如：

```text
<离散数学,数据结构>
<数据结构,算法设计>
```

`<a,b>` 表示 a 必须排在 b 前面。程序输出节点数、关系数、拓扑排序结果以及是否完成全部枚举。存在有向环时不输出拓扑序，而是返回一条具体环路。

## 3 核心流程

1. 按行读取关系文本并检查格式。
2. 对重复关系去重，对错误输入记录行号。
3. 建立节点集合、邻接表和入度表。
4. 使用三色深度优先搜索检测有向环。
5. 图中无环时，使用零入度节点回溯枚举拓扑序。
6. 达到结果上限时停止继续保存，并标明结果未完全枚举。
7. 将结果返回给界面或导出为 TXT 文件。

## 4 核心算法伪代码

```text
枚举拓扑序(当前序列, 当前零入度节点):
    如果当前序列包含全部节点:
        保存该序列
        如果结果数量超过上限:
            标记未完全枚举并停止
        返回

    依次选择每个零入度节点:
        将节点加入当前序列
        临时减少其后继节点的入度
        把新出现的零入度节点加入候选集合
        递归枚举
        恢复入度和候选集合
```

## 5 复杂度说明

- 文本解析和图构建：`O(V + E)`。
- 环检测：`O(V + E)`。
- 单个拓扑序可在线性时间内产生，但全部拓扑序的数量可能呈指数级增长，最坏情况下接近 `V!`。
- 为避免结果数量过大导致程序长时间无响应，默认最多保存 1000 个结果，并允许调用者修改上限。

## 6 异常处理

- 中文逗号、缺少尖括号、空节点和字段过多：返回具体错误行号。
- 重复关系：去重并警告。
- 自环或普通有向环：返回一条具体环路。
- 空输入：提示没有有效关系。
- 文件不存在、编码错误或结果无法写入：返回文件错误。

## 7 技术二接入方式

```python
from toposort_core import solve_text

result = solve_text(input_text, max_results=1000)
```

界面根据 `result.errors`、`result.has_cycle`、`result.orders` 和 `result.is_complete` 显示对应状态，不需要访问核心模块内部数据。
