## 4 技术二接入

```python
from toposort_core import solve_text

result = solve_text(input_text, max_results=1000)
```

界面只需要使用：

- `result.errors`：输入错误
- `result.warnings`：重复关系等警告
- `result.has_cycle` 和 `result.cycle`：环检测结果
- `result.orders`：拓扑排序结果
- `result.is_complete`：是否完成全部枚举
- `result.stop_reason`：停止原因
- `result.node_count` 和 `result.edge_count`：数据规模
