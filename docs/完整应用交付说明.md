## 4 启动方法

首次运行：

1. 安装 Python 3.12。
2. 双击 `安装依赖.bat`。
3. 双击 `启动应用.bat`。

启动入口会立即退出终端窗口，并在主界面加载时显示启动画面。`launcher.vbs`可完全隐藏终端；`run_app.bat`用于排查启动错误。

VS Code 运行方法见根目录 `README.md`；完整操作流程见[使用说明](使用说明.md)。
